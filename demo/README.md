# Demos

Example workflows showcasing different use cases for the workflow language.

| Demo | Description |
|------|-------------|
| [ai_advisor](ai_advisor/) | GUIDE paper advising pipeline — resolves a target paper on arXiv, processes related papers, and synthesizes a rubric-based academic advising report. |
| [ai_deep_research](ai_deep_research/) | Automated web research pipeline using BFS-style exploration with interactive clarification, parallel deep search, and report synthesis. |
| [ai_scientists](ai_scientists/) | End-to-end scientific paper generation combining idea generation (Thinker) and paper writing (Writer) into LaTeX-ready drafts. |

See each demo's README for setup instructions and usage details.
